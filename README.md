# MyHealth

MyHealth is a comprehensive mobile patient health portal and lifestyle tracking application designed to streamline personal medical records and daily wellness monitoring into a single, intuitive interface.

**Full Information on [Documentaions.md](https://github.com/ItzBladeX/MyHealth/blob/main/Documentation.md)**

## Features

### 1. Digital Health ID & Personal Profile

* **MyHealth ID Modal**: Displays core patient identification data fields. It lists the user’s full name (Moti Niguse), phone number (+25193865012), and blood type (O+). 

---
### 2. Allergies & Conditions Tracker

* **Current Medical Listing**: Displays active user health alerts using colored tags. It identifies Peanut and Penicillin as allergies, and Asthma as a chronic condition.

* **Interactive Editing Modal**: A popup interface that allows users to append a new allergy or condition. It includes a text entry box with placeholders (e.g., Sulfa, Latex, Eczema...) and three specific classification buttons to set severity: "Severe Allergy", "Mild Allergy", and "Chronic Condition".

---

### 3. Patient Baseline & Daily Wellness Home

* **Patient Baseline Summary**: A quick-reference widget at the top of the home screen showing the verified blood type labeled with corresponding properties. alongside quick badges for documented allergies (Peanut) and chronic conditions (Asthma).

*  **Digital Screen Time Tracker**: Displays a "Screen Time" module tracking a daily screen time usage

*  **Hydration Tracker**: A progress bar component tracking a fluid consumption goal. 


### 4. Unified Medical History Timeline

* **Medical History**: An aggregated timeline log showing medical history and hospital visits.
